# Barber Digital Profile — Version 1

A simple one-page barber website.

## Files

- `index.html` — page structure/content
- `style.css` — design
- `script.js` — barber information + OPEN/CLOSED status

## Change barber information

Open `script.js` and edit:

- `name`
- `logo`
- `isOpen`
- `openingText`
- `photo`
- `whatsapp`
- `instagram`
- `location`

## Publish for free

1. Create a GitHub account.
2. Create a new repository, e.g. `barber-profile`.
3. Upload the 3 website files.
4. Import the repository into Vercel.
5. Deploy.
6. Vercel gives you a public URL.

No database is required for Version 1.

## Important

The OPEN/CLOSED switch in this version is controlled in `script.js`.
That means the barber cannot change it from the website yet.

In Version 2, this can be connected to a small admin dashboard + Supabase so the barber can change OPEN/CLOSED from their phone.
